# Step 3c: Chat UI, Run Tree, Plan Review and Run Control Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Researchly its chat UI. Projects and threads become real views, the thread streams a run through assistant-ui's AG-UI runtime, and our own panels show the live run tree, the plan-review and clarifying-question interrupts, the budget, and run control (pause, resume, cancel, branch). Four small read endpoints and one event field close the gaps 3b left. F1.1–F1.7 end with E2E specs.

**Architecture:**
- **Pins (exact, no caret):** `@assistant-ui/react@0.15.32`, `@assistant-ui/react-ag-ui@0.1.1`, `@ag-ui/client@1.0.4`. Recorded in ADR 0012 (new frontend section), not a new ADR: same protocol boundary.
- **One agent per thread** (`features/chat/agent.ts`): an `@ag-ui/client` `HttpAgent` whose injected `fetch` is the adapter between AG-UI's `RunAgentInput` and our REST API. A new user message means `POST /api/v1/threads/{id}/runs`; anything else attaches to the run we already know. Every request then streams `POST /api/v1/runs/{id}/stream?after=<lastSeq>`, and a pass-through transform reads the `id:` lines so a reconnect resumes at the right sequence.
- **Our panels, not assistant-ui's nested messages** (binding, research Q3 items 4 and 5): a reducer fed by `agent.subscribe({ onEvent })` holds the run tree (`SUBAGENT_*`, `TOOL_CALL_*`), the todos (`STATE_SNAPSHOT`), the budget (`CUSTOM cost`), the outcome (`CUSTOM run_summary`) and the open interrupt (`RUN_FINISHED` with an interrupt outcome). assistant-ui renders the transcript and the composer only.
- **Interrupts are answered over REST**, not through `RunAgentInput.resume`: our stream endpoint ignores its request body, so the review panel calls `POST /api/v1/runs/{id}/resume` with `decisions`, then re-attaches the agent.
- **New backend reads:** `q=` on `listThreads` (F1.1 "searchable"), `GET /api/v1/efforts` (the tier catalogue and the pre-run estimate range, F1.7), `GET /api/v1/runs/{id}/checkpoints` (the branch picker, F1.6), and `tokens` on the `CUSTOM cost` event (F1.5 "tokens").
- **Three test layers** (research Q5): Vitest renders the real runtime over a stubbed `fetch` that serves a committed SSE transcript; Playwright replays the same transcript through `route.fulfill`; one full-stack `@smoke` Quick run uses `RecordReplay`. No test asserts a message id, an interrupt id or token timing.

**Tech Stack:** React 19, TypeScript 6.0.3 strict, Vite 8, TanStack Router/Query, Base UI + Tailwind v4, i18next, Vitest + Testing Library, Playwright 1.64.1. Backend: Python 3.12, FastAPI, SQLAlchemy 2 async.

**Spec:** `docs/superpowers/specs/2026-10-28-researchly-design.md` (§3 F1.1–F1.7, §4.2, §6.3, §6.4, §17, §18, §19.1, §19.5, §21, §24).
- Research: `docs/research/2026-11-07-step3-streaming-ui.md` (**R-ui**) — Q3 (assistant-ui and `@ag-ui/client` surface), Q4 (SSE through the guard and Vite), Q5 (test layers) and its "Decisions for the plan" are settled and binding.

## Rulings made while planning

Controller rulings (given):

1. **R1 — F1.8 is not in 3c.** The spec says a citation chip "opens the reader at the passage", and the reader is F3.4 in step 4. Chips land in 3d; their click target lands in step 4. 3c renders the answer as plain text, so a `[cite:...]` marker shows literally until 3d.
2. **R2 — F2.5 (saved searches and alerts) is not in step 3.** The build order lists it under step 9.
3. **R3 — 3c includes backend work.** F1.1 needs chat history to be searchable and 3b deferred it. The search endpoint lands here, and the OpenAPI client is regenerated (CI fails on a stale client).
4. **R4 — The frontend pins extend `docs/adr/0012-ag-ui-streaming.md`** with a frontend section rather than adding a new ADR: it is the same protocol boundary.
5. **Scope:** projects and threads UI, the chat thread on the AG-UI runtime, the live run tree, plan-review and clarifying-question interrupts, the effort selector, the budget estimate/confirm and the 80%/100% behaviours, run control, thread search, and the E2E specs that let F1.1–F1.7 flip.

Rulings added while planning (each verified against the installed `ag_ui` 1.0.0 models, the published `@ag-ui/client@1.0.4` and `@assistant-ui/react-ag-ui@0.1.1` type declarations, and this repo's code):

6. **The agent is an `HttpAgent` with an injected `fetch`, not a `run()` override.** `HttpAgentConfig` in 1.0.4 is `{ url, headers?, fetch?, ...AgentConfig }` and `AgentConfig` carries `threadId` and `initialMessages`. An injected `fetch` is `async`, so it can create the run and then open the stream, which `requestInit()` (synchronous) cannot. Overriding `run()` would mean importing `rxjs` directly — a fourth dependency nobody approved. R-ui Q3's "thin `HttpAgent` subclass" is honoured in substance: one small adapter around the same class.
7. **A new turn is detected by the last message's id.** The runtime re-sends the whole transcript on every drive. If the last message is a user message whose id differs from the one we last sent, it is a new turn (`POST /threads/{id}/runs`); otherwise we attach to the known run. The ref is seeded from the thread's persisted messages, so a reload never duplicates a run.
8. **Interrupts are answered over REST.** `POST /runs/{id}/stream` ignores its body (ADR 0012), so `useAgUiSubmitInterruptResponses` would post `resume` into a void. The review panel calls `resumeRun` with `decisions` and then re-attaches. For the same reason the open interrupt is read from our own reducer, not from `useAgUiInterrupts`.
9. **The transcript is hydrated from the server, not from the event log.** The agent is built with `initialMessages` from `getThread`, and we attach the stream only when the thread's latest run is still live (`pending`, `running`, `paused`, `awaiting_user`). A finished run's answer is already a thread message, so replaying it would double it.
10. **The run tree shows status and elapsed time per node, and tokens and cost per run.** AG-UI carries no per-node usage; the only token source on the wire is the `CUSTOM cost` event, which is run-wide. Spec F1.5's "tokens and cost" is met by the run header. Per-node usage would need a new backend event — deferred.
11. **The pre-run estimate is a tier-derived range,** served by `GET /api/v1/efforts` as `budget × 0.25 … budget × 1.00`, marked with a `ponytail:` comment. A ledger-based estimate needs run history nobody has yet.
12. **The confirmation threshold is a browser preference** (`localStorage`, default `1.00`), because F9 Settings is step 9 and no settings endpoint exists. It moves to Settings → Budgets when F9 lands.
13. **Dialogs use the native `<dialog>` element.** It gives a focus trap, Escape and a backdrop with no new dependency and no shadcn registry install; only `components/ui/button.tsx` exists today and nothing here needs more.
14. **No new routes.** `/` is the projects view and `/p/$id/chat/$thread` is the chat view, both already in `routeTree.gen.ts`. Opening a project opens its newest thread, creating one first if it has none.
15. **F1.4's enforcement stays backend-tested.** The tier limits are enforced in `agents/` and covered by 3a's tests; the E2E spec asserts that the selector sets the run's effort and that the view shows it.
16. **F1.6's "runs survive an app restart" stays backend-tested** (`RunManager.resume_running`, 3a/3b). 3c's E2E covers pause, resume, cancel and branch through the UI. The restart journey is `@journey` work in step 10.
17. **The full-stack `@smoke` run is a Quick run whose fixture calls no tool.** The app has no HTTP replay mode (vcrpy is a pytest fixture), so any recorded tool call would hit the network from CI. Quick skips plan review (F1.3), which makes it the shortest honest full-stack path; every interrupt behaviour is covered on the frozen transcript.

```python
@router.get("/projects/{project_id}/threads", operation_id="listThreads", responses=NOT_FOUND)
async def list_threads(
    project_id: uuid.UUID, runs: Manager, q: Annotated[str | None, Query(max_length=200)] = None
) -> list[ThreadOut]:
    """The project's threads, newest first. `q` keeps those whose title or any message contains it (F1.1)."""
    stmt = select(Thread).where(Thread.project_id == project_id)
    if q:
        # ponytail: ILIKE over the message text; add a trigram index when a project holds thousands of threads
        like = f"%{q}%"
        text_matches = select(Message.id).where(
            Message.thread_id == Thread.id, Message.content["text"].astext.ilike(like)
        )
        stmt = stmt.where(or_(Thread.title.ilike(like), text_matches.exists()))
    await get_or_404(runs, Project, project_id)
    stmt = stmt.order_by(Thread.created_at.desc(), Thread.id.desc())
    async with runs.sessions() as session:
        return [ThreadOut.model_validate(t) for t in await session.scalars(stmt)]
```

```ts
import { readFileSync } from "node:fs"

export type Frame = { seq: number; type: string; data: string }

/** The committed transcript, parsed. One source of truth with the Playwright specs. */
export function frames(name = "standard-run"): Frame[] {
  const text = readFileSync(new URL(`../../e2e/fixtures/agui/${name}.sse`, import.meta.url), "utf-8")
  return text
    .split("\n\n")
    .filter((block) => block.trim())
    .map((block) => {
      const seq = Number(/^id: (\d+)$/m.exec(block)![1])
      const data = /^data: (.*)$/m.exec(block)![1]
      return { seq, type: JSON.parse(data).type as string, data }
    })
}

/** The run as it stands when the plan interrupt arrives: everything up to and including that RUN_FINISHED. */
export function untilInterrupt(name = "standard-run"): Frame[] {
  const all = frames(name)
  return all.slice(0, all.findIndex((f) => f.type === "RUN_FINISHED" && f.data.includes('"interrupt"')) + 1)
}

export function sse(list: Frame[]): Response {
  const body = list.map((f) => `id: ${f.seq}\ndata: ${f.data}\n\n`).join("")
  return new Response(body, { headers: { "content-type": "text/event-stream" } })
}
```

```ts
import { HttpAgent, type Message as AgentMessage } from "@ag-ui/client"

import { api, ApiError } from "@/api/client"
import { type EffortName, type Message, unwrap } from "@/api/queries"

/** What the browser knows about the run this thread is streaming. The fetch adapter reads and writes it. */
export type RunRef = {
  runId: string | null
  lastSeq: number
  lastUserMessageId: string | null
  effort: EffortName
}

export function newRunRef(messages: Message[], effort: EffortName): RunRef {
  const lastUser = messages.filter((m) => m.role === "user").at(-1)
  return { runId: null, lastSeq: 0, lastUserMessageId: lastUser?.id ?? null, effort }
}

export function toAgentMessages(messages: Message[]): AgentMessage[] {
  return messages.map((m) =>
    m.role === "user"
      ? { id: m.id, role: "user" as const, content: m.text }
      : { id: m.id, role: "assistant" as const, content: m.text }
  )
}

/** Keep `ref.lastSeq` on the stream's `id:` lines without changing the bytes the parser sees. */
function trackSeq(response: Response, ref: RunRef): Response {
  if (!response.body) return response
  const decoder = new TextDecoder()
  let buffer = ""
  const tap = new TransformStream<Uint8Array, Uint8Array>({
    transform(chunk, controller) {
      buffer += decoder.decode(chunk, { stream: true })
      const lines = buffer.split("\n")
      buffer = lines.pop() ?? "" // an id line split across chunks finishes in the next one
      for (const line of lines) {
        if (line.startsWith("id:")) ref.lastSeq = Number(line.slice(3).trim()) || ref.lastSeq
      }
      controller.enqueue(chunk)
    },
  })
  return new Response(response.body.pipeThrough(tap), {
    status: response.status,
    headers: response.headers,
  })
}

/**
 * The adapter between AG-UI's RunAgentInput and our REST API (ADR 0012).
 *
 * A last message that is a user message we have not sent starts a run; anything else attaches to the run
 * we already know. Either way the answer is the SSE stream, resumed at the last sequence we saw.
 */
export function makeFetch(threadId: string, ref: RunRef) {
  return async (_url: RequestInfo | URL, init?: RequestInit): Promise<Response> => {
    const body = JSON.parse(String(init?.body ?? "{}")) as {
      messages?: { id: string; role: string; content?: string }[]
    }
    const last = body.messages?.at(-1)
    if (last?.role === "user" && last.id !== ref.lastUserMessageId) {
      const run = unwrap(
        await api.POST("/api/v1/threads/{thread_id}/runs", {
          params: { path: { thread_id: threadId } },
          body: { message: String(last.content ?? ""), effort: ref.effort },
        })
      )
      ref.runId = run.id
      ref.lastSeq = 0
      ref.lastUserMessageId = last.id
    }
    if (ref.runId === null) throw new ApiError(409)
    const stream = await fetch(
      `${window.location.origin}/api/v1/runs/${ref.runId}/stream?after=${ref.lastSeq}`,
      { method: "POST", headers: { accept: "text/event-stream" }, signal: init?.signal ?? null }
    )
    if (!stream.ok) throw new ApiError(stream.status)
    return trackSeq(stream, ref)
  }
}

export function createAgent(threadId: string, messages: Message[], ref: RunRef): HttpAgent {
  return new HttpAgent({
    threadId,
    initialMessages: toAgentMessages(messages),
    url: `${window.location.origin}/api/v1/runs`, // never requested: the fetch above picks the real URL
    fetch: makeFetch(threadId, ref),
  })
}
```

```tsx
import type { HttpAgent } from "@ag-ui/client"
import { createContext, useContext, useEffect, useReducer, type ReactNode } from "react"

/** Only the fields we read. Typing this structurally keeps @ag-ui/core out of our dependency list. */
export type AgUiEvent = { type: string } & Record<string, unknown>

export type NodeStatus = "running" | "done"
export type AgentNode = {
  id: string
  name: string
  status: NodeStatus
  startedAt: number
  endedAt: number | null
}
export type ToolNode = AgentNode & { agentId: string }
export type Todo = { content: string; status: string }
export type Cost = { spentUsd: number; budgetUsd: number; tokens: number }
export type Summary = { status: string; spentUsd: number; budgetUsd: number; coverage: number }
export type ReviewAction = { name: string; text: string; decisions: string[] }
export type Review = { id: string; actions: ReviewAction[] }

export type RunState = {
  agents: AgentNode[]
  tools: ToolNode[]
  todos: Todo[]
  cost: Cost | null
  review: Review | null
  summary: Summary | null
  failed: boolean
}

export const LEAD = "lead"

export const EMPTY: RunState = {
  agents: [],
  tools: [],
  todos: [],
  cost: null,
  review: null,
  summary: null,
  failed: false,
}

function num(value: unknown): number {
  return typeof value === "number" ? value : Number(value ?? 0)
}

function started(id: string, name: string): AgentNode {
  return { id, name, status: "running", startedAt: Date.now(), endedAt: null }
}

function finish<T extends AgentNode>(nodes: T[], id: string): T[] {
  return nodes.map((n) => (n.id === id ? { ...n, status: "done" as const, endedAt: Date.now() } : n))
}

function withLead(agents: AgentNode[]): AgentNode[] {
  return agents.some((a) => a.id === LEAD) ? agents : [started(LEAD, LEAD), ...agents]
}

/** An HITL review (ADR 0012): its actions come from the raw interrupt, its decisions from the schema. */
function toReview(interrupt: Record<string, unknown>): Review {
  const schema = interrupt.responseSchema as
    | { properties?: { decisions?: { prefixItems?: { properties?: { type?: { enum?: string[] } } }[] } } }
    | undefined
  const items = schema?.properties?.decisions?.prefixItems ?? []
  const raw = (interrupt.metadata as { langgraph?: { raw?: { action_requests?: unknown[] } } } | undefined)
    ?.langgraph?.raw?.action_requests
  const requests = (raw ?? []) as { name?: string; args?: { plan?: string; question?: string } }[]
  const names = String(interrupt.reason ?? "")
    .replace(/^researchly:/, "")
    .split("+")
  return {
    id: String(interrupt.id),
    actions: items.map((item, index) => ({
      name: requests[index]?.name ?? names[index] ?? "",
      text:
        requests[index]?.args?.plan ?? requests[index]?.args?.question ?? String(interrupt.message ?? ""),
      decisions: item.properties?.type?.enum ?? [],
    })),
  }
}

export function reduce(state: RunState, event: AgUiEvent): RunState {
  switch (event.type) {
    case "RUN_STARTED": // a new drive supersedes the previous one's outcome
      return { ...state, agents: withLead(state.agents), review: null, summary: null, failed: false }
    case "SUBAGENT_STARTED": {
      const id = String(event.subagentRunId)
      if (state.agents.some((a) => a.id === id)) return state
      return { ...state, agents: [...withLead(state.agents), started(id, String(event.name))] }
    }
    case "SUBAGENT_FINISHED":
    case "SUBAGENT_ERROR":
      return { ...state, agents: finish(state.agents, String(event.subagentRunId)) }
    case "TOOL_CALL_START": {
      const id = String(event.toolCallId)
      if (state.tools.some((t) => t.id === id)) return state // a resume repeats its pending call
      const node = started(id, String(event.toolCallName))
      return {
        ...state,
        agents: withLead(state.agents),
        tools: [...state.tools, { ...node, agentId: String(event.subagentRunId ?? LEAD) }],
      }
    }
    case "TOOL_CALL_END":
      return { ...state, tools: finish(state.tools, String(event.toolCallId)) }
    case "STATE_SNAPSHOT":
      return { ...state, todos: (event.snapshot as { todos?: Todo[] } | undefined)?.todos ?? [] }
    case "CUSTOM": {
      const value = (event.value ?? {}) as Record<string, unknown>
      if (event.name === "cost") {
        const cost = {
          spentUsd: num(value.spent_usd),
          budgetUsd: num(value.budget_usd),
          tokens: num(value.tokens),
        }
        return { ...state, cost }
      }
      if (event.name === "run_summary") {
        const summary = {
          status: String(value.status),
          spentUsd: num(value.spent_usd),
          budgetUsd: num(value.budget_usd),
          coverage: num(value.coverage),
        }
        return { ...state, summary }
      }
      return state
    }
    case "RUN_FINISHED": {
      const outcome = event.outcome as { type?: string; interrupts?: Record<string, unknown>[] } | undefined
      if (outcome?.type !== "interrupt" || !outcome.interrupts?.length) return state
      return { ...state, review: toReview(outcome.interrupts[0]) }
    }
    case "RUN_ERROR":
      return { ...state, failed: true }
    default:
      return state
  }
}

const Context = createContext<RunState>(EMPTY)

export function useRunState(): RunState {
  return useContext(Context)
}

export function RunStateProvider({ agent, children }: { agent: HttpAgent; children: ReactNode }) {
  const [state, dispatch] = useReducer(reduce, EMPTY)
  useEffect(() => {
    const subscription = agent.subscribe({
      onEvent: ({ event }: { event: unknown }) => dispatch(event as AgUiEvent),
    })
    return () => subscription.unsubscribe()
  }, [agent])
  return <Context.Provider value={state}>{children}</Context.Provider>
}
```

```tsx
import { AssistantRuntimeProvider, ComposerPrimitive, MessagePrimitive, ThreadPrimitive } from "@assistant-ui/react"
import { useAgUiRuntime } from "@assistant-ui/react-ag-ui"
import { useQuery } from "@tanstack/react-query"
import { useEffect, useRef, useState } from "react"
import { useTranslation } from "react-i18next"

import {
  type Effort,
  type EffortName,
  effortsQuery,
  LIVE_STATUSES,
  runQuery,
  type ThreadDetail,
  threadQuery,
} from "@/api/queries"
import { Button } from "@/components/ui/button"
import { createAgent, newRunRef } from "@/features/chat/agent"
import { RunStateProvider } from "@/features/chat/run-state"

const DEFAULT_THRESHOLD = 1

/**
 * Above this many dollars a run asks before it starts (F1.7).
 * ponytail: one localStorage number, no server round-trip. It moves into Settings with F9.
 */
function threshold(): number {
  const stored = Number(localStorage.getItem("researchly.budget-threshold"))
  return Number.isFinite(stored) && stored > 0 ? stored : DEFAULT_THRESHOLD
}

const dollars = (value: string | number) => `$${Number(value).toFixed(2)}`

export function ChatThread({ projectId, threadId }: { projectId: string; threadId: string }) {
  const { t } = useTranslation()
  const { data: thread } = useQuery(threadQuery(threadId))
  const last = thread?.messages.at(-1)
  // only a trailing user message can belong to a run that has not answered yet
  const candidate = last?.role === "user" ? (last.run_id ?? null) : null
  const { data: run, isPending: runPending } = useQuery(runQuery(candidate))

  if (!thread || (candidate !== null && runPending)) return <p>{t("chat.loading")}</p>
  const live = run && LIVE_STATUSES.includes(run.status) ? run.id : null
  return <Runtime key={threadId} projectId={projectId} thread={thread} live={live} />
}

function Runtime({
  projectId,
  thread,
  live,
}: {
  projectId: string
  thread: ThreadDetail
  live: string | null
}) {
  const { t } = useTranslation()
  const { data: efforts = [] } = useQuery(effortsQuery)
  const [effort, setEffort] = useState<EffortName>("standard")
  const [, setRunId] = useState<string | null>(live)
  // one ref and one agent per mounted thread; the key above remounts them when the thread changes
  const [ref] = useState(() => {
    const created = newRunRef(thread.messages, effort)
    created.runId = live
    return created
  })
  const [agent] = useState(() => createAgent(thread.id, thread.messages, ref))
  ref.effort = effort // the composer always sends the current selection
  ref.onRun = setRunId
  const runtime = useAgUiRuntime({ agent })

  useEffect(() => {
    if (live) void agent.runAgent() // replay the live run instead of asking again
  }, [agent, live])

  const selected = efforts.find((option) => option.name === effort)
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <RunStateProvider agent={agent}>
        <section aria-label={t("chat.conversation")} className="flex min-w-0 flex-1 flex-col gap-3">
          <ThreadPrimitive.Root className="flex min-h-0 flex-1 flex-col">
            <ThreadPrimitive.Viewport className="flex-1 overflow-y-auto">
              <ThreadPrimitive.Messages components={{ Message: Bubble }} />
            </ThreadPrimitive.Viewport>
            <Composer effort={effort} efforts={efforts} selected={selected} onEffort={setEffort} />
          </ThreadPrimitive.Root>
        </section>
      </RunStateProvider>
    </AssistantRuntimeProvider>
  )
  // projectId is the panel's home in Task 12; keeping it here now would be an unused prop
}

function Bubble() {
  return (
    <MessagePrimitive.Root className="mb-3 whitespace-pre-wrap text-sm">
      <MessagePrimitive.Parts />
    </MessagePrimitive.Root>
  )
}

function Composer({
  effort,
  efforts,
  selected,
  onEffort,
}: {
  effort: EffortName
  efforts: Effort[]
  selected: Effort | undefined
  onEffort: (effort: EffortName) => void
}) {
  const { t } = useTranslation()
  const [pending, setPending] = useState<HTMLFormElement | null>(null)
  const dialog = useRef<HTMLDialogElement>(null)
  const over = selected !== undefined && Number(selected.budget_usd) > threshold()

  useEffect(() => {
    if (pending) dialog.current?.showModal()
    else dialog.current?.close()
  }, [pending])

  const confirm = () => {
    const form = pending
    setPending(null)
    form?.requestSubmit() // the guard lets it through: `pending` is null again
  }

  return (
    <div
      onSubmitCapture={(event) => {
        if (!over || pending) return
        event.preventDefault() // capture runs before the composer's own submit
        event.stopPropagation()
        setPending(event.target as HTMLFormElement)
      }}
    >
      <ComposerPrimitive.Root className="flex flex-col gap-2 border-t pt-3">
        <ComposerPrimitive.Input
          aria-label={t("chat.ask")}
          placeholder={t("chat.ask")}
          className="min-h-16 w-full resize-none rounded-md border p-2 text-sm"
        />
        <div className="flex items-center gap-3">
          <label className="text-sm">
            <span className="sr-only">{t("chat.effort")}</span>
            <select
              aria-label={t("chat.effort")}
              value={effort}
              onChange={(event) => onEffort(event.target.value as EffortName)}
              className="h-8 rounded-md border px-2 text-sm"
            >
              {efforts.map((option) => (
                <option key={option.name} value={option.name}>
                  {t(`chat.efforts.${option.name}`)}
                </option>
              ))}
            </select>
          </label>
          {selected && (
            <p className="text-muted-foreground text-sm">
              {t("chat.estimate", {
                low: dollars(selected.estimate_low_usd),
                high: dollars(selected.estimate_high_usd),
                budget: dollars(selected.budget_usd),
              })}
            </p>
          )}
          <ComposerPrimitive.Send className="ml-auto h-8 rounded-md bg-primary px-3 text-sm text-primary-foreground">
            {t("chat.send")}
          </ComposerPrimitive.Send>
        </div>
      </ComposerPrimitive.Root>
      <dialog ref={dialog} aria-label={t("chat.confirmTitle")} className="rounded-md border p-4">
        <p className="text-sm">
          {t("chat.confirmBody", {
            effort: t(`chat.efforts.${effort}`),
            budget: dollars(selected?.budget_usd ?? 0),
          })}
        </p>
        <div className="mt-3 flex justify-end gap-2">
          <Button type="button" variant="outline" size="sm" onClick={() => setPending(null)}>
            {t("chat.cancel")}
          </Button>
          <Button type="button" size="sm" onClick={confirm}>
            {t("chat.confirm")}
          </Button>
        </div>
      </dialog>
    </div>
  )
}
```

```tsx
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query"
import { useState } from "react"
import { useTranslation } from "react-i18next"

import { api } from "@/api/client"
import { checkpointsQuery, LIVE_STATUSES, runQuery, unwrap } from "@/api/queries"
import { Button } from "@/components/ui/button"
import { useRunState } from "@/features/chat/run-state"

const WRAP_UP = 0.8 // the budget guard injects its wrap-up instruction here (spec §6.4)
const dollars = (value: string | number) => `$${Number(value).toFixed(2)}`

export function RunPanel({ runId, onReattach }: { runId: string; onReattach: (runId?: string) => void }) {
  const { t } = useTranslation()
  const queryClient = useQueryClient()
  const state = useRunState()
  const { data: run } = useQuery(runQuery(runId))
  const [branching, setBranching] = useState(false)
  const [checkpoint, setCheckpoint] = useState("")

  const control = useMutation({
    mutationFn: async (action: "pause" | "resume" | "cancel") =>
      unwrap(
        await api.POST(`/api/v1/runs/{run_id}/${action}` as "/api/v1/runs/{run_id}/pause", {
          params: { path: { run_id: runId } },
        })
      ),
    onSuccess: async (updated) => {
      await queryClient.invalidateQueries({ queryKey: ["run", runId] })
      if (updated.status === "running") onReattach() // a resume opens a new AG-UI run on the same stream
    },
  })

  const branch = useMutation({
    mutationFn: async (checkpointId: string) =>
      unwrap(
        await api.POST("/api/v1/runs/{run_id}/branch", {
          params: { path: { run_id: runId } },
          body: { checkpoint_id: checkpointId },
        })
      ),
    onSuccess: (child) => {
      setBranching(false)
      onReattach(child.id)
    },
  })

  const live = run !== undefined && LIVE_STATUSES.includes(run.status)
  const cost = state.cost ?? (run ? { spentUsd: Number(run.spent_usd), budgetUsd: Number(run.budget_usd), tokens: 0 } : null)
  const share = cost && cost.budgetUsd > 0 ? cost.spentUsd / cost.budgetUsd : 0

  return (
    <aside aria-label={t("run.panel")} className="flex w-72 shrink-0 flex-col gap-4 border-l pl-4">
      {cost && (
        <section className="flex flex-col gap-1">
          <progress aria-label={t("run.budget")} value={cost.spentUsd} max={cost.budgetUsd} className="w-full" />
          <p className="text-sm">{t("run.spent", { spent: dollars(cost.spentUsd), budget: dollars(cost.budgetUsd) })}</p>
          {cost.tokens > 0 && <p className="text-muted-foreground text-xs">{t("run.tokens", { tokens: cost.tokens })}</p>}
          {share >= 1 ? (
            <p role="status" className="text-sm">{t("run.stopped")}</p>
          ) : share >= WRAP_UP ? (
            <p role="status" className="text-sm">{t("run.wrapUp")}</p>
          ) : null}
        </section>
      )}

      {state.summary && (
        <p className="text-sm font-medium">
          {t("run.summary", {
            status: state.summary.status,
            spent: dollars(state.summary.spentUsd),
            coverage: Math.round(state.summary.coverage * 100),
          })}
        </p>
      )}
      {state.failed && <p role="alert" className="text-sm">{t("run.failed")}</p>}

      <section className="flex flex-col gap-1">
        <h2 className="text-sm font-medium">{t("run.activity")}</h2>
        <ul aria-label={t("run.activity")} className="flex flex-col gap-1 text-sm">
          {state.agents.map((agent) => (
            <li key={agent.id}>
              <span className={agent.status === "running" ? "font-medium" : ""}>{agent.name}</span>
              <span className="sr-only"> {t(`run.status.${agent.status}`)}</span>
              <ul className="ml-4 flex flex-col text-muted-foreground">
                {state.tools
                  .filter((tool) => tool.agentId === agent.id)
                  .map((tool) => (
                    <li key={tool.id}>
                      {tool.name}
                      <span className="sr-only"> {t(`run.status.${tool.status}`)}</span>
                    </li>
                  ))}
              </ul>
            </li>
          ))}
        </ul>
      </section>

      {state.todos.length > 0 && (
        <section className="flex flex-col gap-1">
          <h2 className="text-sm font-medium">{t("run.todos")}</h2>
          <ul aria-label={t("run.todos")} className="flex flex-col gap-1 text-sm">
            {state.todos.map((todo) => (
              <li key={todo.content} className={todo.status === "completed" ? "text-muted-foreground line-through" : ""}>
                {todo.content}
              </li>
            ))}
          </ul>
        </section>
      )}

      <section className="flex flex-wrap gap-2">
        {run?.status === "running" && (
          <Button type="button" size="sm" variant="outline" onClick={() => control.mutate("pause")}>
            {t("run.pause")}
          </Button>
        )}
        {run?.status === "paused" && (
          <Button type="button" size="sm" onClick={() => control.mutate("resume")}>
            {t("run.resume")}
          </Button>
        )}
        {live && (
          <Button type="button" size="sm" variant="outline" onClick={() => control.mutate("cancel")}>
            {t("run.cancel")}
          </Button>
        )}
        <Button type="button" size="sm" variant="outline" onClick={() => setBranching((open) => !open)}>
          {t("run.branch")}
        </Button>
      </section>

      {branching && <BranchPicker runId={runId} value={checkpoint} onChange={setCheckpoint} onBranch={branch.mutate} />}
    </aside>
  )
}

function BranchPicker({
  runId,
  value,
  onChange,
  onBranch,
}: {
  runId: string
  value: string
  onChange: (checkpointId: string) => void
  onBranch: (checkpointId: string) => void
}) {
  const { t } = useTranslation()
  const { data: checkpoints = [] } = useQuery(checkpointsQuery(runId))
  const chosen = value || checkpoints[0]?.checkpoint_id || ""
  return (
    <section className="flex flex-col gap-2">
      <label className="text-sm">
        <span className="sr-only">{t("run.checkpoint")}</span>
        <select
          aria-label={t("run.checkpoint")}
          value={chosen}
          onChange={(event) => onChange(event.target.value)}
          className="h-8 w-full rounded-md border px-2 text-sm"
        >
          {checkpoints.map((entry) => (
            <option key={entry.checkpoint_id} value={entry.checkpoint_id}>
              {new Date(entry.created_at).toLocaleTimeString()} · {entry.next.join(", ") || t("run.end")}
            </option>
          ))}
        </select>
      </label>
      <Button type="button" size="sm" disabled={!chosen} onClick={() => onBranch(chosen)}>
        {t("run.branchFrom")}
      </Button>
    </section>
  )
}
```

```tsx
import { Button } from "@/components/ui/button"

type Decision = Record<string, unknown> & { type: string }

export function Review({ runId, onAnswered }: { runId: string; onAnswered: () => void }) {
  const { t } = useTranslation()
  const { review } = useRunState()
  // one draft per action, keyed by its position: the plan starts from the agent's text, an answer starts empty
  const [drafts, setDrafts] = useState<Record<number, string>>({})

  const resume = useMutation({
    mutationFn: async (decisions: Decision[]) =>
      unwrap(
        await api.POST("/api/v1/runs/{run_id}/resume", {
          params: { path: { run_id: runId } },
          body: { decisions: decisions as never },
        })
      ),
    onSuccess: () => {
      setDrafts({})
      onAnswered()
    },
  })

  if (!review) return null
  const draft = (index: number, action: ReviewAction) =>
    drafts[index] ?? (action.decisions.includes("respond") ? "" : action.text)
  const send = (decision: Decision) => resume.mutate([decision])

  return (
    <section aria-label={t("review.panel")} className="flex flex-col gap-2 rounded-md border p-3">
      {review.actions.map((action, index) => {
        const value = draft(index, action)
        const answering = action.decisions.includes("respond")
        return (
          <div key={action.name} className="flex flex-col gap-2">
            <h2 className="text-sm font-medium">{answering ? t("review.question") : t("review.plan")}</h2>
            {answering && <p className="text-sm">{action.text}</p>}
            <textarea
              aria-label={answering ? t("review.answer") : t("review.planLabel")}
              value={value}
              onChange={(event) => setDrafts({ ...drafts, [index]: event.target.value })}
              className="min-h-24 w-full rounded-md border p-2 text-sm"
            />
            <div className="flex flex-wrap gap-2">
              {answering ? (
                <Button type="button" size="sm" disabled={!value.trim() || resume.isPending} onClick={() => send({ type: "respond", message: value })}>
                  {t("review.send")}
                </Button>
              ) : (
                <>
                  <Button type="button" size="sm" disabled={resume.isPending} onClick={() => send({ type: "approve" })}>
                    {t("review.approve")}
                  </Button>
                  <Button
                    type="button"
                    size="sm"
                    variant="outline"
                    disabled={value === action.text || resume.isPending}
                    onClick={() =>
                      send({ type: "edit", edited_action: { name: action.name, args: { plan: value } } })
                    }
                  >
                    {t("review.approveEdits")}
                  </Button>
                  <Button type="button" size="sm" variant="outline" disabled={resume.isPending} onClick={() => send({ type: "reject" })}>
                    {t("review.reject")}
                  </Button>
                </>
              )}
            </div>
          </div>
        )
      })}
    </section>
  )
}
```

```ts
import { resolve } from "node:path"

import type { Page, Route } from "@playwright/test"

import { repo } from "./paths"

type Frame = { seq: number; data: string }

function frames(): Frame[] {
  const text = readFileSync(resolve(repo, "e2e/fixtures/agui/standard-run.sse"), "utf-8")
  return text
    .split("\n\n")
    .filter((block) => block.trim())
    .map((block) => ({
      seq: Number(/^id: (\d+)$/m.exec(block)![1]),
      data: /^data: (.*)$/m.exec(block)![1],
    }))
}

const project = { id: "p1", name: "Hallucination", created_at: "2026-11-13T10:00:00Z" }
const thread = { id: "t1", project_id: "p1", title: "Retrieval augmentation", created_at: "2026-11-13T10:00:00Z" }
const efforts = [
  { name: "quick", scouts: 0, readers: 0, tool_calls: 10, budget_usd: "0.10", estimate_low_usd: "0.03", estimate_high_usd: "0.10" },
  { name: "standard", scouts: 4, readers: 4, tool_calls: 25, budget_usd: "1.00", estimate_low_usd: "0.25", estimate_high_usd: "1.00" },
  { name: "deep", scouts: 8, readers: 12, tool_calls: 40, budget_usd: "5.00", estimate_low_usd: "1.25", estimate_high_usd: "5.00" },
]

const json = (route: Route, body: unknown, status = 200) =>
  route.fulfill({ status, contentType: "application/json", body: JSON.stringify(body) })

export async function mockRun(page: Page): Promise<void> {
  const all = frames()
  // the run stops at the plan interrupt until a resume arrives, exactly as the backend does
  const interrupt = all.findIndex((frame) => frame.data.includes('"interrupt"')) + 1
  let until = interrupt
  let status = "running"
  const run = () => ({
    id: "r1",
    project_id: "p1",
    thread_id: "t1",
    parent_run_id: null,
    effort: "standard",
    status,
    plan: null,
    budget_usd: "1.00",
    spent_usd: "0.84",
    branch_from_checkpoint: null,
    started_at: "2026-11-13T10:00:00Z",
    ended_at: null,
  })

  await page.route("**/api/v1/projects", (route) => json(route, [project]))
  await page.route("**/api/v1/projects/p1/threads*", (route) => {
    const q = new URL(route.request().url()).searchParams.get("q")
    const match = !q || thread.title.toLowerCase().includes(q.toLowerCase())
    return route.request().method() === "POST" ? json(route, thread, 201) : json(route, match ? [thread] : [])
  })
  await page.route("**/api/v1/threads/t1", (route) => json(route, { ...thread, messages: [] }))
  await page.route("**/api/v1/efforts", (route) => json(route, efforts))
  await page.route("**/api/v1/threads/t1/runs", (route) => json(route, run(), 201))
  await page.route("**/api/v1/runs/r1", (route) => json(route, run()))
  await page.route("**/api/v1/runs/r1/resume", (route) => {
    until = all.length
    status = "running"
    return json(route, run())
  })
  await page.route("**/api/v1/runs/r1/pause", (route) => {
    status = "paused"
    return json(route, run())
  })
  await page.route("**/api/v1/runs/r1/cancel", (route) => {
    status = "cancelled"
    return json(route, run())
  })
  await page.route("**/api/v1/runs/r1/stream*", (route) => {
    const after = Number(new URL(route.request().url()).searchParams.get("after") ?? 0)
    const body = all
      .slice(0, until)
      .filter((frame) => frame.seq > after)
      .map((frame) => `id: ${frame.seq}\ndata: ${frame.data}\n\n`)
      .join("")
    return route.fulfill({ status: 200, contentType: "text/event-stream", body })
  })
}
```

## Open risks

1. **`MessagePrimitive.Parts` in 0.15.32.** Older assistant-ui called it `Content`. Task 11 Step 1 prints the real
   export before any code is written; if the name differs, use the one in the dist and change nothing else.
2. **`HttpAgentConfig.fetch`.** Ruling 6 rests on it. Task 9 Step 6 prints the declaration if typecheck rejects it.
   If it is gone, the fallback is a subclass overriding `requestInit` plus a `fetch` wrapper — not an rxjs import.
3. **Streams under jsdom.** `frontend/tests/*.test.tsx` drive a real `ReadableStream` through the AG-UI parser.
   Vitest's jsdom environment keeps Node's `Response` and `TransformStream`, so this should hold; if a test fails on
   a missing stream global rather than on behaviour, move that one file to `// @vitest-environment node` and keep the
   DOM tests where they are.
4. **`<dialog>.showModal()`** needs jsdom ≥ 26; the repo is on jsdom 30. If a future bump regresses it, render the
   dialog with the `open` attribute instead and keep `aria-label`.
5. **Capture-phase submit.** The budget guard cancels the composer's submit from a wrapping `div`'s

   assistant-ui's handler. The thread test proves it; if React changes this, move the guard onto
   `ComposerPrimitive.Root` itself.
6. **`agent.runAgent()`** is the attach path for a live run, a resume and a branch. It is `AbstractAgent`'s public
